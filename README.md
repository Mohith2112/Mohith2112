### 🟣 Userspace TCP/IP Stack
*(tinystack)*

A complete TCP/IP stack in C++ running entirely in userspace via macOS `utun` — zero OS networking calls, zero external libraries. Implements the full RFC 793 TCP state machine, reaching **0.21 ms average** ICMP round-trips with **0% packet loss** over 40 packets.

**Tech:** `C++20` `CMake` `TCP/IP` `ICMP` `TUN/TAP`
