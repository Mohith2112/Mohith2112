## 🚀 Featured Projects

<details>
<summary><b>🔹 Userspace TCP/IP Stack (tinystack)</b></summary>
<br/>

A complete TCP/IP stack written in C++, running entirely in userspace via macOS `utun` — zero OS networking calls, zero external libraries, raw bytes only. Implements the full RFC 793 TCP state machine end-to-end.

| Attribute | Details |
|---|---|
| **Stack** | C++20, CMake, ICMP, TCP, RFC 793, TUN/TAP, non-blocking I/O, RFC 1071 checksum |
| **Scale** | Full TCP state machine: LISTEN → SYN RECEIVED → ESTABLISHED → FIN → CLOSED |
| **Performance** | 0.21 ms average ICMP round-trip, 0% packet loss over 40 packets |
| **Security** | Raw packet parsing with manual checksum verification, no reliance on OS network stack |
| **Impact** | Full HTTP/1.0 request/response cycles handled entirely outside the kernel network stack |
| **Demo** | [Watch Demo](https://asciinema.org/a/AfidtQWsDJLPtf2H) |
| **Repository** | [View Repository](https://github.com/Mohith2112/tinystack) |

Designed an internal packet router supporting both a TCP server on port 8080 and an outbound TCP client, proving the stack could handle real bidirectional traffic without relying on any existing networking libraries — every byte parsed and constructed by hand.

</details>

<details>
<summary><b>🔹 Audio Deepfake Detector</b></summary>
<br/>

A CNN-based spoofed-speech classifier trained on the ASVspoof 2019 LA dataset, built to distinguish genuine from synthetic speech even on attack types withheld from training.

| Attribute | Details |
|---|---|
| **Stack** | Python, PyTorch, Librosa, NumPy, Pandas, Scikit-learn, Streamlit |
| **Scale** | Trained on 121,000+ audio samples across multiple spoofing attack types |
| **Performance** | 23.93% Equal Error Rate on unseen attack types |
| **Security** | Fixed a critical data-leakage bug via systematic audio trimming to ensure valid evaluation |
| **Impact** | ~90% reduction in parameter count while correcting a 9:1 class imbalance via weighted sampling |
| **Demo** | [Try it on Hugging Face Spaces](https://huggingface.co/spaces/Mickeylabs/audio-deepfake-detector) |
| **Repository** | [View Repository](https://github.com/Mohith2112/audio-deepfake-detector) |

Built a Mel-spectrogram pipeline feeding a 4-block CNN with Batch Normalisation and Global Average Pooling, then added Grad-CAM explainability so predictions could be visually interpreted rather than treated as a black box.

</details>

<details>
<summary><b>🔹 NeonAura AI — XR Hand-Tracking Platform</b></summary>
<br/>

A zero-backend, fully client-side XR application that turns a standard webcam into a gesture-controlled motion platform using computer vision in the browser.

| Attribute | Details |
|---|---|
| **Stack** | JavaScript (ES6), Three.js, MediaPipe Hands, WebGL, Canvas API |
| **Scale** | 10+ distinct gesture interactions, six visual themes, an AR mode |
| **Performance** | 30%+ reduction in frame latency across all gesture interactions |
| **Security** | Entirely client-side — no server dependencies, no data leaves the browser |
| **Impact** | Delivered an Air Drawing Studio with live letter recognition and a shader-based CGI Liquid Hand with physics-driven finger deformation |
| **Demo** | [Launch App](https://neonaura-ai.vercel.app/app.html) |
| **Repository** | [View Repository](https://github.com/Mohith2112/neonaura-ai) |

Released as a fully browser-based experience with real-time hand-skeleton tracking, proving high-fidelity interactive graphics and CV inference can run entirely on the client with no backend infrastructure at all.

</details>
